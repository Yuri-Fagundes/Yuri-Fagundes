## 🚀 Projetos em destaque

### 🤖 RH Assist AI — Assistente inteligente com RAG

Assistente virtual baseado em IA generativa que responde dúvidas sobre políticas e procedimentos internos a partir de documentos utilizados como fonte de conhecimento.

**💡 Principais funcionalidades e conceitos:**
- 📄 Consulta de documentos como fonte de conhecimento.
- 🔎 Recuperação de trechos relevantes por busca semântica.
- 🧠 Utilização de LLM para contextualizar e gerar respostas.
- 🎯 Respostas fundamentadas nos documentos disponibilizados.
